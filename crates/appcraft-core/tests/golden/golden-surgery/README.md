# Golden Surgery

## Install

Tell Cursor, Claude, Antigravity, or OpenCode: **Install this.**

Run this from the repository root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\install-craft.ps1
```

Installs the Windows app, the CLI, and the MCP bundle.

Generated by AppCraft (`desktop_egui` viewer v1). Read-only viewer over the
local SQLite file `golden-surgery.dbcraft`.

## Run

cargo run -- [--db PATH]

Without `--db` it opens `./golden-surgery.dbcraft` in the working directory.

## Patient portal (LAN demo)

`cargo run --bin __PACKAGE__-portal -- --port 11540`
then open http://127.0.0.1:11540 — home, new-patient onboarding,
appointments, treatment plans (record number), staff inbox, photos.
Reception uploads room/shop/floorplan photos at /staff/media.
Binds loopback only; no login in v1 — demo, not for real patient
data over networks (see docs/LEGAL-SPIKE.md, network chapter).

## Data + legal

Personal data lives in `golden-surgery.dbcraft` (local SQLite, no network calls in
this binary). A legal-spike review (`docs/LEGAL-SPIKE.md` in the project)
is required before loading real personal data. Sample seed rows (if any)
are synthetic — replace at intake, never ship, never back up anywhere.
