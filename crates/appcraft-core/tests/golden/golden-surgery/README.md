# Golden Surgery

Generated by AppCraft (`desktop_egui` viewer v1). Read-only viewer over the
local SQLite file `golden-surgery.dbcraft`.

## Run

cargo run -- [--db PATH]

Without `--db` it opens `./golden-surgery.dbcraft` in the working directory.

## Data + legal

Personal data lives in `golden-surgery.dbcraft` (local SQLite, no network calls in
this binary). A legal-spike review (`docs/LEGAL-SPIKE.md` in the project)
is required before loading real personal data. Sample seed rows (if any)
are synthetic — replace at intake, never ship, never back up anywhere.
